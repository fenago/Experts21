# Critical review

## Steps

1. Restate the recommendation in one sentence.
2. List its key assumptions and check each against `docs/` numbers (e.g., rent ≤ 10% of sales, ~340 transactions/day break-even, $15 minimum wage, 2–4+ month permits).
3. Find the **weakest assumption** — the one that, if wrong, breaks the plan.
4. Describe the realistic worst case and its cost.
5. Look for what's missing: an expert not consulted, a risk from docs/09 not addressed, data that should exist but doesn't.
6. Check for group-think: are experts repeating each other's numbers without independent sources?
7. Say what evidence would change your verdict.

## Output

```
**Verdict:** Proceed / Proceed with conditions / Rethink
**Weakest assumption:** ...
**Worst case:** ...
**Missing:** ...
**Conditions to proceed:** 1. ... 2. ...
```

Be direct and specific. Criticize the plan, not the people. Don't invent problems to look thorough.
