Ask for:

  1. Limit the personal guarantee. The offer requires it for the full 7-year term. Ask for a cap or one that ends after a set period.
  2. Add an exclusive-use clause. None is offered, so another coffee tenant could open in the building.
  3. Lower the 4% yearly increases, or fix them for the first years.
  4. Raise the tenant improvement allowance ($25/sq ft now) and the free rent (3 months now).
  5. Ask for more time. The offer expires December 15, 2026. Don't let the date set your pace.
