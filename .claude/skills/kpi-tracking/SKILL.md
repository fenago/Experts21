# KPI tracking

## Core KPIs and targets (docs/05, docs/09)

| KPI | Target / warning |
|---|---|
| Daily transactions | Model break-even ~340; warning under ~250 after 3 months |
| Average ticket | $8–$10 with food (Estimate) |
| Labor % of sales | 30–35%; warning above 40% for a month |
| COGS % | 25–32% |
| Prime cost (COGS + labor) | ≤ 65% |
| Occupancy % | ≤ 10% |
| Sales per labor hour | Track by daypart |
| Repeat-customer rate | From loyalty data; trend up |
| Google rating / review count | ≥ 4.5; warning below 4.3 |
| Speed of service | Set a target after testing the bar |
| Cash reserve | Warning below 2 months of fixed costs |
| Marketing | Cost per new customer vs. customer lifetime value; redemptions per campaign |

## Reporting

Weekly one-page dashboard: this week vs. last week vs. target, with 3 notes (what changed, why, what we'll do). Data from POS, scheduling, accounting, Google, social analytics.

Before opening, use the targets as the plan; after opening, use actuals.
