# Deliverables

Working outputs from the expert agents (models, plans, checklists, SOPs, scorecards). Agents save here by topic, for example:

- `finance/` — budgets, P&L and break-even models
- `sites/` — site scorecards and lease comparisons
- `competition/` — competitor tables
- `menu/` — menu drafts and recipe costing
- `operations/sops/` — standard operating procedures
- `risk/` — risk register, hurricane plan
- `plan/` — project plan and timeline

The research these build on is in [`docs/`](../docs/README.md).
