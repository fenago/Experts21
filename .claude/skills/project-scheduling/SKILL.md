# Project scheduling

## Typical phases (docs/04, docs/06)

| Phase | Typical duration | Depends on |
|---|---|---|
| Concept, budget, funding | 1–3 months | — |
| Site search and lease (LOI → signed) | 1–3 months | budget |
| Design and drawings | 1–2 months | signed lease |
| Permit plan review | 2–4+ months in Miami | drawings |
| Build-out | 2–4 months | permits |
| Inspections, CO, DBPR license, BTRs | 2–6 weeks | build-out |
| Hiring and training | 4–6 weeks before opening | opening date |
| Brand, launch marketing | starts 8–12 weeks before opening | name chosen |
| Equipment ordering | lead times vary (often several weeks — get quotes) | layout final |

Total: usually 6–12 months from lease to opening.

## Rules

1. Mark the **critical path** (usually lease → drawings → permits → build-out → final inspections).
2. Run non-critical work in parallel (brand, hiring, menu, tech).
3. Show the **rent start date vs. opening date** gap and its cost.
4. Output a table: task, owner (agent or person), start week, end week, depends on, status. Update it, don't restart it.
