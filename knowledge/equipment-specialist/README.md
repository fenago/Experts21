# Knowledge folder — Kenji, Coffee Equipment & Bar Engineering Specialist

`equipment-specialist` reads **every file in this folder before answering any question**. Put documents here that only this expert needs, or that it needs more than the rest of the team.

## What belongs here

- Equipment quotes and spec sheets
- Warranty and service agreements
- Water test results

## What doesn't belong here

- Research for the whole team → `docs/`
- Outputs the agents produce → `deliverables/`
- Passwords, account numbers, Social Security numbers, or other sensitive personal data. This folder is pushed to GitHub.

## How to add a document

1. Drop the file in this folder. Markdown or plain text works best; PDFs, CSVs, and spreadsheets also work.
2. Name it `YYYY-MM-DD-short-topic.ext`, for example `2027-01-10-quote-or-notes.md`.
3. At the top of a Markdown or text file, add one line saying where the information came from and when.
4. If another expert needs the same document, copy it into their folder too (or ask for it to go into `docs/`).

Newer documents here take priority over the November 2026 research in `docs/`; the agent will say when they conflict.
