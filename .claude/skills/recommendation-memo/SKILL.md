# Recommendation memo

Readers are a business consultant and Dr. Lee. Write in plain language, short sentences, no unexplained jargon. Default length: under 400 words unless asked for more.

## Template

```
**Bottom line:** [1–3 sentences: the answer or recommendation]

**Why**
- [reason with a number and source]
- [reason]

**Key numbers** (table if more than three)

**Risks / what would change my mind**
- [risk] → [how to reduce it]

**Assumptions** [only the ones that matter]

**Needs from other experts** [HANDOFF lines, if any]

**Next steps**
1. [action] — [who] — [when]
```

## Rules

- Lead with the answer, not the process.
- Give one recommendation. If you list options, say which you'd choose.
- Use tables for comparisons; bullets for reasons.
- Save long deliverables (models, plans, checklists) to `deliverables/<topic>/` and link them in the memo.
