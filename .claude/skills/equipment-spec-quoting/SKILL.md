# Equipment specification and quoting

## Size to volume

Base sizing on peak drinks per hour (7–10 AM) and the menu mix. Price ranges are in docs/04 (e.g., 2–3 group espresso machine $15K–$35K; grinders $3K–$6K each; ice machine $4K–$8K).

## Miami-specific needs

- **Ice:** iced drinks dominate. Estimate lbs/day from iced drinks × ice per drink, then add ~50% buffer (Estimate).
- **Water filtration:** essential for taste and to protect machines from scale — test local water hardness and size the system to the machine maker's specs.
- **Heat load:** espresso machines and ovens add heat; coordinate HVAC with buildout-design-advisor.
- **Power and plumbing:** dedicated circuits (often 208–240V), water lines, floor drains — confirm with each spec sheet.
